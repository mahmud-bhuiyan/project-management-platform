Provision company admin

Onboard a new company with an owner account and organization — ready for team setup in Phase 3.

What gets created

  • Company admin user with secure credentials
  • New organization with unique slug
  • Owner membership linking admin to org

After provisioning

The company admin signs in and adds team members. No public signup — every user is invited by an admin.

Flow

  1. 1 Create admin + organization
  2. 2 Admin adds team (Phase 3)
  3. 3 Projects & tasks go live
